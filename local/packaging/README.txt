Zed Local 1.27.0 (c8666d44)
Локальная сборка Zed для Windows x64
=====================================

Состав
------
- zedlocal.exe  - локальная сборка Zed
- cli.exe       - CLI
- conpty.dll, OpenConsole.exe - терминал
- amd_ags_x64.dll - AMD GPU Services
- agents\codex-acp - локальный ACP-мост Codex с исправлением вопросов
- Install.cmd   - установка в профиль пользователя
- Portable.cmd  - запуск без установки, данные рядом с программой
- Uninstall.cmd - удаление программы; пользовательские данные сохраняются
- Check-Update.cmd - ручная проверка обновления

Автообновление
--------------
После установки ярлыки запускают ZedLocalLauncher.vbs. При каждом запуске
он проверяет последний релиз форка на GitHub, скачивает новый ZIP,
проверяет SHA256 и ставит новую версию рядом со старой. Затем запускается
уже новая версия. Если сети нет или проверка не удалась, запускается
текущая версия.

Это не фоновая служба: проверка выполняется только в момент запуска.
Открытый Zed не перезапускается и не прерывается. Пользовательские данные
в %LOCALAPPDATA%\ZedLocal\UserData не затрагиваются.

Журнал обновлений:
  %LOCALAPPDATA%\ZedLocal\updates\update.log
Ручная проверка:
  Check-Update.cmd

Установка
---------
1. Распакуйте ZIP в любую папку.
2. Запустите Install.cmd.
3. Запускайте Zed Local с ярлыка на рабочем столе или из меню «Пуск».

Программа ставится в:
  %LOCALAPPDATA%\Programs\ZedLocal\builds\<версия>

Данные (история, настройки, чаты) хранятся отдельно:
  %LOCALAPPDATA%\ZedLocal\UserData

В архив не входят история, ключи, чаты, настройки и профили агентов.
При первом запуске Zed Local создаёт новый профиль. Аккаунты и настройки
агентов нужно подключить заново.

Портативный режим
-----------------
Запустите Portable.cmd. Данные будут рядом с exe, в папке UserData.
В портативном режиме автообновление не используется.

Удаление
--------
Запустите Uninstall.cmd из распакованной папки или из папки программы.
Ярлыки и файлы лаунчера удаляются; папка
%LOCALAPPDATA%\ZedLocal\UserData сохраняется.

Внешние агенты
--------------
- OpenCode устанавливается отдельно (registry/offline addon) и требует
  собственной авторизации.
- codex-acp уже лежит в agents\codex-acp. Чтобы использовать его, укажите
  в settings.json путь к index.js внутри установленной сборки и путь к
  codex.exe в CODEX_PATH. Пример есть в agents\codex-acp\README.txt.

Требования
----------
- Windows 10/11 x64.
- Microsoft Visual C++ Redistributable 2015-2022 (x64).
- Microsoft Edge WebView2 Runtime - для HTML-предпросмотра.
- Node.js - только если используется codex-acp.

Что изменено
------------
Zed 1.27.0 с локальными доработками: ACP 3.6.0/subagents, native Codex,
история/форки/переименование, недельный лимит Codex, индикатор лимита
OpenCode Go, исправление статуса вопросов агентов и восстановления сессии
при втором экземпляре.
Официальная подпись отсутствует; сборка локальная.

Проверка целостности
--------------------
SHA256SUMS.txt содержит хеши файлов программы. Install.ps1 проверяет их
перед установкой, а автообновление проверяет SHA256 всего ZIP.
